# alacritty-gogh-themes
[Gogh themes](https://gogh-co.github.io/Gogh/) ported to alacritty toml files and a python script to generate them with no nonsense.

To use them, just use an import in your [alacritty.toml config](https://alacritty.org/config-alacritty.html):

```
[general]
import = ["~/alacritty-themes/monokai-soda.toml"]
[font]
size = 16
normal = {family = "Iosevka Term"}
```
